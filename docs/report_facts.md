# Numbers of the report and where they are stored

One row per number. "Printed" is the value in the report, "stored" the value in the result file at higher precision.
Result files without a folder are in `sim/results/`. A key that names `analysis/paper_numbers.json` gives the entry of that file
that holds the same value, computed from the result file by `analysis/make_paper_numbers.py`.
Percentages of HGI_E divide by the value in `sim/results/multi_bench_crn.json`. ± is a 95% batch-means half-width unless a row says standard error.
Runs with `cap = per_pattern` and runs with the flags off are outside Definition 2.3.
